# Academic-Grade-Calculator
A robust Python utility designed for student performance analysis.
This script utilizes complex logical structures, including nested conditions and logical operators,
to calculate letter grades and provide academic feedback based on a 0-100 marking scale.
A Python-based logic tool developed to automate student grading using real-world academic business rules.
🚀 Features
Input Validation: Automatically handles invalid marks (outside the 0-100 range) and prevents crashes from non-numeric entries.
Logical Operators: Uses and and or operators to determine grade boundaries with high precision.
Nested Business Rules: Features a specialized "Attendance Boost" where a student can earn a B grade with a score of 65 if they have good attendance.
Marks Range,Grade,Message
90 - 100,A+,Excellence achieved! Keep it up. 
80 - 89,A,Great job! You have a solid understanding. 
70 - 79 (or 65+ with Attendance),B,Good work. You've cleared comfortably. 
50 - 69,C,Passed. Consider reviewing advanced modules. 
40 - 49,D,Marginal Pass. Eligible for a retake. 
< 40,F,Fail. Please schedule a meeting with your counselor. 
Informative Feedback: Provides tailored status messages for every grade level to encourage student progress.
